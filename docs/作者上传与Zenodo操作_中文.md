# 代码公开的剩余操作

代码已按作者授权准备MIT许可；数据来源说明、复现脚本和聚合表已同步。无需重新上传整个ZIP。

当前连接不能切换仓库可见性。请打开仓库 https://github.com/xiaobeiyi6-netizen/comparative-sentiment-validity ，进入Settings → General → Danger Zone → Change repository visibility，选择Public并完成GitHub确认。操作完成后重新核对未登录访问状态，再更新论文为实际公开链接。

以后如需长期归档，可使用正式归档服务取得真实的版本DOI；未取得前不填DOI。代码公开不等于机构伦理审查完成，伦理及同意适用性应依据真实机构结论另行更新。原始推文、账号字段、文本哈希映射和逐条预测不会因为代码MIT许可而自动获得同一许可。
